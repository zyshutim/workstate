## 状态定义

- 已验证：代码和真实运行结果均已检查。
- 代码存在：仓库中已有实现，本轮未重新完成端到端验证。
- 部分实现：已有基础结构，与当前 PRD 仍有差距。
- 未实现：当前代码没有对应完整能力。
- 待迁移：仍运行旧模型，需要按 PRD 替换。
